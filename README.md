Shortcut Arena, a training app that turns learning keyboard shortcuts into a fast-paced, interactive challenge. 
It is not that most people don't know these keyboard shortcuts; the gap is a lack of muscle 💪 memory to use them, and that is what Shortcut Arena is trying to bridge.
Yes, most people know keyboard shortcuts exist but never build the muscle memory to use them.
Shortcut Arena turns the process into a fun game, helping you go from slow clicking to fast, efficient workflows in a fun, repeatable way.

This is specially made for students, developers, and everyday computer users who want to work faster but don’t want to sit through boring tutorials. 

It’s especially useful for beginners and intermediates, web2 and web3 surfers trying to level up productivity.
